# System Logs Dashboard

Нативный iOS-проект на SwiftUI: системные логи, фильтры, переключение темы, настройки отображения и кнопка `БУМ`, которая создаёт 1000 всплывающих окон одновременно.

## Структура

- `SwiftUIApp/SystemLogsAppApp.swift` — точка входа приложения
- `SwiftUIApp/ContentView.swift` — интерфейс, логика фильтрации и эффект `БУМ`

## Что есть

- список системных логов;
- поиск по тексту;
- фильтр по уровню и source;
- переключение темы dark/light;
- кнопка `БУМ`, которая показывает 1000 overlay-окон с текстом `БУМ`.

## Важно

Это SwiftUI-приложение для iOS, а не HTML-страница. Чтобы получить `.ipa`, нужно:

- открыть проект в Xcode на Mac;
- собрать архив;
- экспортировать `.ipa`.

Прямо в браузере `.ipa` собрать нельзя.
