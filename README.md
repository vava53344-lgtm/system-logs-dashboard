# System Logs Dashboard

Простой проект в репозитории: системные логи, фильтры, тема, и кнопка `БУМ`, которая создаёт много всплывающих окон с текстом `БУМ`.

## Запуск

Откройте файл `index.html` в браузере.

## Что внутри

- лог-таблица;
- поиск по тексту;
- фильтр по уровню и source;
- переключение темы dark/light;
- кнопка `БУМ` с эффектом 1000 окон.

## Важно про iOS / .ipa

Файл `.ipa` нельзя собрать прямо здесь в браузере. Для iOS нужно:

- открыть проект в Xcode на Mac;
- собрать архив;
- экспортировать `.ipa`.

Для SwiftUI-версии исходники лежат в папке `SwiftUIApp/`.
